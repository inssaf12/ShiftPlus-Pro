# ShiftPlus Pro - Gestión de Turnos
App Android para gestión de turnos de empleados.

**Tecnologías:** Java, Android Studio, SQLite, Docker

**Funcionalidades:**
- Asignación de turnos por administrador
- Consulta de horarios por empleados
- Gestión de plantilla
